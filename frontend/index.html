Variables

Any text you write — prompt blocks, character description/personality, world setting, place descriptions, persona description — can use {{these}}. Unset ones quietly become an empty string; anything not in the list below is left exactly as typed, unchanged.

This is separate from the standard prompt blocks (World Info, Character Description, etc.) you insert from the dropdown on the Prompts page — those decide what's included in the request; variables below just fill in text wherever you write them.

Freeroam keys · endpoint · models · prompts

Endpoint

Defaults to OpenRouter, but any OpenAI Chat Completions–compatible endpoint works — point it elsewhere and use that service's key below.

Reasoning effort only applies on OpenRouter. When a model returns a thinking trace, it shows as a collapsible "Show thinking" note above its reply.

Memory

How relevant a memory has to be (0–1 cosine similarity) before it's recalled into context. Small local embedding models can rate a memory as similar just for sharing one common word with what's being said, even when it's not actually related — raise this if characters bring up unrelated memories too often; lower it if they're not recalling things they should.

Suggested actions

How replies are scanned for quick-action suggestions ("send to", "add place", "add character") — all local, no extra LLM call. Regex only is instant but only fires on specific phrasing. ML only uses a local NER + intent-classification model, more robust to varied phrasing but slower per message. Regex + ML runs both and merges the results.

Model

Pick any model id the endpoint serves. Pricing (per 1M tokens) shows when the endpoint reports it.
